Works on DaVinci Resolve Free

Let Claude edit, grade and render in DaVinci Resolve

An open-source MCP server (Model Context Protocol) that gives Claude real control over DaVinci Resolve 21.0.4 Free on Windows. It reads every change back, so Claude always knows the true state of your project.

Features

75 tools + full API

Projects, media pool, timelines, Inspector, Fusion, render queue, and all 381 scripting methods via api_call.

Verified writes

Every write returns {requested, actual, ok}. Snapshots, diff_state and an op log show exactly what changed.

Color grading with power windows

Wheels, saturation and circle windows written as DRX and applied on the Color page. The result is verified by pixels.

Workarounds for API gaps

Razor, trims, transitions and speed changes on a new timeline, plus Fusion keyframes and offline audio fades/normalize.

Safe by default

confirm=true for destructive actions, a .drp backup first, dry-run, backup grade versions.

Local only

Loopback socket with a per-session token. No cloud calls, no telemetry.

Quick start

Needs DaVinci Resolve 21.0.4 Free. Resolve 21.1+ Free removed Python scripting, so do not update.
  1. Clone the repo and run install.ps1 in PowerShell.
  2. Restart Claude Desktop.
  3. In Resolve, open a project and click Workspace → Scripts → ClaudeBridge.
  4. Ask Claude, e.g. "Cut clip 3 at 5 seconds and add a cross dissolve" or "Brighten the subject on the left with a soft circle window and show me the frame".
git clone https://github.com/justhung69/resolve-mcp
cd resolve-mcp
powershell -ExecutionPolicy Bypass -File install.ps1

Tiếng Việt

resolve-mcp là MCP server mã nguồn mở giúp Claude AI điều khiển DaVinci Resolve bản Free (21.0.4) trên Windows:

  • Dựng phim: cắt, trim, transition, đổi tốc độ.
  • Màu: chỉnh màu có power window.
  • Xuất: render.
  • Kiểm tra: mọi thay đổi đều được đọc lại để xác nhận.

Cài bằng install.ps1. Sau đó, mỗi lần mở Resolve, bấm Workspace → Scripts → ClaudeBridge. Hướng dẫn đầy đủ bằng tiếng Việt có trong README.
